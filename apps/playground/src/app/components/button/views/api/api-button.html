API reference for Button

CSS classes only — no Angular component required.

Import

@use '@quai/quai-components/styles';

Base class

Class Description
.buttonBase button styles. Required on all buttons.

Variants

Class Description
.button--primarySolid dark background, white text.
.button--secondaryTransparent with border.
.button--ghostNo background or border.
.button--destructiveError color background.

Sizes

Class Height Font size
.button--sm2rem0.875rem
(default)2.25rem0.875rem
.button--lg2.75rem1rem

States

State Behavior
:hoverBackground color change per variant.
:activeScale down to 0.97.
:focus-visible2px outline, 2px offset.
:disabledOpacity 0.5, no pointer events.
