Tabs

Navegación por pestañas con soporte de rutas, divider opcional y datos genéricos por tab.

Uso básico

<quai-tabs [tabs]="tabs" [divider]="true" />

Propiedades

Input Tipo Default Descripción
tabs QuaiTabInterface[] undefined Array de tabs con label, route opcional y data genérica.
divider boolean false Muestra una línea divisoria debajo de la lista de tabs.

Interfaz

interface QuaiTabInterface<T = Record<string, unknown>> {
  label: string;
  route?: string;
  data?: T;
}
