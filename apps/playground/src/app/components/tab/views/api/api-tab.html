API reference for Tabs

import { QuaiTabs, QuaiTabInterface } from '@quai/quai-components';

Selector

quai-tabs

Inputs

Name Type Default Description
tabs QuaiTabInterface[] undefined Array of tab items.
divider boolean false Shows a bottom border below the tab list.

QuaiTabInterface

Property Type Required Description
label string Yes Display text of the tab.
route string No Route path for navigation.
data T No Generic payload for custom data.

CSS classes

Class Description
.tabs__list Container for tab buttons.
.tabs__list--divider Adds bottom border to the list.
.tabs__tab Individual tab element.
.tabs__tab--active Active tab state.
.tabs__panel Tab content panel.
