Navigation Menu

Menú de navegación vertical con items opcionales de icono, estado activo y labels de grupo. Basado en el sidebar del design system.

Uso básico

<quai-nav-menu>
  <li class="list__item">Item 1</li>
  <li class="list__item list__item--active">Item 2</li>
</quai-nav-menu>

Con iconos

<quai-nav-menu>
  <li class="list__item">
    <svg class="list__item-icon">...</svg>
    <span>Dashboard</span>
  </li>
</quai-nav-menu>

Con grupo

<quai-nav-menu>
  <span class="list__group-label">General</span>
  <li class="list__item">Dashboard</li>
</quai-nav-menu>
