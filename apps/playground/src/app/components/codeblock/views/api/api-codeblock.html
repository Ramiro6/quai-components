Component API

Properties and methods available on the Quai Code Block component.

Input Properties

Property Type Default Description
title string 'JavaScript' The programming language label displayed in the header

Content Projection

The component accepts code content via <ng-content>:

<quai-codeblock title="TypeScript">
// Your code here
</quai-codeblock>

CSS Classes

Class Description
.codeblock Main container with border and rounded corners
.codeblock__header Header area containing language label and copy button
.codeblock__lang Language label text styling
.codeblock__copy Copy button styling (ghost style)
.codeblock__pre Code container with horizontal scrolling
.codeblock__code Code text with monospace font
