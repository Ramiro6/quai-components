Code Block Component

The Code Block component displays code snippets with language labels and copy-to-clipboard functionality.

Features

  • Display code with language labels
  • Copy to clipboard button
  • Syntax-aware styling with design system tokens
  • Horizontal scrolling for long lines
  • Monospace font for better code readability

When to use

Use the Code Block component to display code examples, snippets, or documentation within your application. It provides a consistent way to present code with proper visual hierarchy and user interactions.
