Características del sistema

Cada componente está diseñado para integrarse de forma natural en productos reales.

Tokens OKLCH

Paleta perceptualmente uniforme con escala zinc de 11 pasos y color de acento violeta.

Tema oscuro nativo

Detección automática con prefers-color-scheme y control manual con persistencia en localStorage.

Accesibilidad WCAG AA

Focus rings, touch targets de 44px, skip-link, ARIA attributes y contraste verificado.

9 componentes

Button, Input, Card, Modal, Navigation, Toggle, Slider, Table y Chips — listos para producción.

Cada componente sigue nomenclatura BEM, soporta ambos temas y es completamente responsive.

CSS puro

Sin preprocesadores, sin frameworks. Custom properties nativas y JavaScript vanilla.

CSS Accesible Modular Ligero

Mobile-first

Breakpoints sm, md y lg con min-width. Espaciado fluido con clamp() y safe-area-inset.
